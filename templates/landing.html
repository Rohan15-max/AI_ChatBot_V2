SHEET C‑01  ·  CAPABILITIES

What it actually does

Not a wrapper around one API call — a working system with memory, retrieval, and judgment about which model to use.

ROUTING

Cost-aware fallback

Picks the right model for the job and automatically falls back if a provider is down or rate-limited.

RETRIEVAL

Hybrid RAG

Vector search fused with keyword search, reranked, so answers stay grounded in your own uploaded documents.

MEMORY

Long-term recall

Remembers relevant facts about you across sessions, weighted by importance, fading like real memory does.

AGENT

Autonomous tool use

Breaks a task into steps and calls tools — calculator, web search — to get a grounded answer, not a guess.

STREAMING

Real-time responses

Token-by-token delivery over WebSocket, tuned for the shortest possible time to first word.

EFFICIENCY

Semantic caching

Recognizes near-duplicate questions and skips the redundant model call entirely.
